用刚发布的二进制，而不是本机 `target/release`：

```bash
cd /tmp && rm -rf fcm-verify && mkdir fcm-verify && cd fcm-verify
CH=/mnt/e/FastCrossMap/paper/sample_data/hg19ToHg38.over.chain.gz

# 下载最新 linux 资产（版本无关，无需手写 0.6.0）

  | grep -o 'https://github.com/[^"]*fcm-[^"]*-linux-x86_64\.tar\.gz' | head -1 \
  | xargs -I{} curl -fLO {}

# 版本要对
"$FCM" --version                      # 期望 fast-crossmap 0.6.0

#   两边都应报告 100 条、全部映射
```
